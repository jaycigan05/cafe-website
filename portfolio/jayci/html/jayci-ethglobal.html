My Web3 Journey

Through ETHGlobal, I started my journey into Web3 as a complete newcomer, learning the fundamentals of decentralised technology from the ground up. I studied how Layer 1 blockchains such as Ethereum act as the base settlement layer that secures transactions and runs smart contracts, and how Layer 2 solutions (such as rollups) build on top of them to make transactions faster and cheaper while still inheriting the security of the base chain.

As my understanding grew, I turned that learning into something practical by helping to create a Genesis Handbook — a beginner-friendly onboarding guide that breaks down core Web3 concepts such as wallets, gas fees, smart contracts, the difference between Layer 1 and Layer 2, and how to safely interact with decentralised applications (dApps) — so that other newcomers can start their own Web3 journey with confidence.
